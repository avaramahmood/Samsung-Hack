Phase 2
Pre-generate MMLU CoT data — offline pass
Session 1 continued · ~1 hour · do once, reuse everywhere
›
Why this step exists
MMLU has no CoT answers — you generate them yourself
MMLU only has multiple choice answers A/B/C/D. For SFT you need reasoning chains. You use the base model itself to generate these, then train on them. This is called self-distillation and is a standard technique.

Phase 4
PEAR SFT — Layer 1 proper
Session 3 · ~4-6 hours · builds on basic SFT success
›
What PEAR adds
Importance-weighted loss — the only difference from basic SFT
Standard SFT treats every token equally. PEAR reweights each token's loss by how much the current model disagrees with the original base model's predictions. Tokens where the model is very confident (base and trained agree) get low weight. Tokens where RL will need to make big changes get high weight. This prepares the model specifically for RL rather than just being a good predictor.
Step 1
Pre-compute behavior policy log probs — one time
import torch from transformers import AutoModelForCausalLM, AutoTokenizer # Load base model FROZEN — this never changes base_model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-7B", torch_dtype=torch.bfloat16).to("cuda") base_model.eval() # critical — never train this # Pre-compute and save log probs for every training sample import pickle def get_log_probs(model, tokenizer, text): inputs = tokenizer(text, return_tensors="pt").to("cuda") with torch.no_grad(): outputs = model(**inputs) log_probs = torch.log_softmax(outputs.logits, dim=-1) # Return token-level log probs token_ids = inputs["input_ids"][0] token_log_probs = log_probs[0, torch.arange(len(token_ids)-1), token_ids[1:]] return token_log_probs.cpu() # Run this on your full training dataset and save # This takes ~1 hour but only runs ONCE behavior_log_probs = {} for i, sample in enumerate(your_dataset): behavior_log_probs[i] = get_log_probs(base_model, tokenizer, sample["text"]) if i % 100 == 0: print(f"{i} done") with open("behavior_log_probs.pkl", "wb") as f: pickle.dump(behavior_log_probs, f) del base_model # free VRAM before training starts torch.cuda.empty_cache()
Step 2
PEAR training with importance-weighted loss
class PEARTrainer(SFTTrainer): def __init__(self, behavior_log_probs, *args, **kwargs): super().__init__(*args, **kwargs) self.behavior_log_probs = behavior_log_probs def compute_loss(self, model, inputs, return_outputs=False): # Standard forward pass outputs = model(**inputs) logits = outputs.logits # Get current model log probs log_probs = torch.log_softmax(logits, dim=-1) token_ids = inputs["input_ids"] # Get importance weights batch_idx = inputs.get("idx", None) if batch_idx is not None: behavior_lp = self.behavior_log_probs[batch_idx.item()].to(logits.device) current_lp = log_probs[0, torch.arange(len(token_ids[0])-1), token_ids[0][1:]] # Importance weight = ratio of current to behavior importance_weights = torch.exp(current_lp - behavior_lp) # Clip to prevent instability importance_weights = torch.clamp(importance_weights, 0.1, 10.0) else: importance_weights = torch.ones(token_ids.shape[1]-1).to(logits.device) # Weighted cross-entropy loss shift_logits = logits[..., :-1, :].contiguous() shift_labels = token_ids[..., 1:].contiguous() loss_fct = torch.nn.CrossEntropyLoss(reduction='none') token_losses = loss_fct(shift_logits.view(-1, shift_logits.size(-1)), shift_labels.view(-1)) weighted_loss = (token_losses * importance_weights.view(-1)).mean() return (weighted_loss, outputs) if return_outputs else weighted_loss # Use exactly like SFTTrainer but with importance weights loaded trainer = PEARTrainer( behavior_log_probs=behavior_log_probs, model=model, tokenizer=tokenizer, train_dataset=your_combined_dataset, # ... same args as before )

Phase 5
PROF-GRPO — Layer 2
Sessions 4-5 · ~6-8 hours · the core RL stage
›
What GRPO is
RL that generates multiple answers and learns which ones were better
For each question, GRPO generates 8 different answers (called rollouts). It then scores each answer (correct/wrong for GSM8K). Answers better than average get positive reward. Worse than average get negative reward. The model updates to produce more of the good answers. PROF adds a step-level PRM to also check whether each reasoning step was valid — not just the final answer.

Step 2
Define reward functions for each dataset
import re def gsm8k_reward(completions, answers, **kwargs): """Returns 1.0 if final answer matches, 0.0 if not""" rewards = [] for completion, answer in zip(completions, answers): # Extract number after #### pred = re.search(r"####\s*([\d,.-]+)", completion) gold = re.search(r"####\s*([\d,.-]+)", answer) if pred and gold: rewards.append(1.0 if pred.group(1).replace(",","") == gold.group(1).replace(",","") else 0.0) else: rewards.append(0.0) return rewards def strategyqa_reward(completions, answers, **kwargs): """Yes/No binary reward""" rewards = [] for completion, answer in zip(completions, answers): pred = "yes" if "yes" in completion.lower()[-50:] else "no" gold = answer.lower().strip() rewards.append(1.0 if pred == gold else 0.0) return rewards def mmlu_replay_reward(completions, answers, **kwargs): """Multiple choice exact match""" rewards = [] for completion, answer in zip(completions, answers): pred_match = re.search(r"\b([ABCD])\b", completion[-100:]) pred = pred_match.group(1) if pred_match else "X" rewards.append(1.0 if pred == answer else 0.0) return rewards def combined_reward(completions, dataset_type, **kwargs): if dataset_type == "gsm8k": return gsm8k_reward(completions, **kwargs) elif dataset_type == "strategyqa": return strategyqa_reward(completions, **kwargs) elif dataset_type == "mmlu": return mmlu_replay_reward(completions, **kwargs)

Phase 7
Curriculum reward shifting — Layer 3
Session 6 · ~3-4 hours · your novel contribution
›
Qwen: 3 stages
Stage weights shift progressively
def make_curriculum_reward(stage): weights = { 1: {"format": 0.6, "accuracy": 0.3, "conciseness": 0.1}, 2: {"format": 0.2, "accuracy": 0.7, "conciseness": 0.1}, 3: {"format": 0.1, "accuracy": 0.4, "conciseness": 0.5}, }[stage] def reward_fn(completions, answers, dataset_type, **kwargs): rewards = [] for completion, answer in zip(completions, answers): # Format reward: has step-by-step structure? fmt = 1.0 if len(completion.split('\n')) > 3 else 0.0 # Accuracy reward: correct answer? acc = combined_reward([completion], [answer], dataset_type=[dataset_type])[0] # Conciseness: exponential decay on length IF correct length = len(completion.split()) concise = acc * max(0, 1 - (length / 200)) if acc > 0 else 0.0 total = (weights["format"] * fmt + weights["accuracy"] * acc + weights["conciseness"] * concise) rewards.append(total) return rewards return reward_fn # Stage 1: 100 steps # Stage 2: 150 steps (trigger when GSM8K accuracy plateaus for 25 steps) # Stage 3: 100 steps
Phi: 2 stages only
Simpler — prevents collapse at 3.8B
# Phi Stage A: format + accuracy combined (100 steps) phi_stage_a_weights = {"format": 0.4, "accuracy": 0.6, "conciseness": 0.0} # Phi Stage B: accuracy + conciseness (80 steps) phi_stage_b_weights = {"format": 0.0, "accuracy": 0.5, "conciseness": 0.5}
